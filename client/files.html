Files Subsystem Documentation
The Files subsystem provides enterprise-grade, sandboxed filesystem manipulation within the web hosting environment. All path resolutions are strictly jailed to the web root (C:\xampp\htdocs), preventing traversal exploits while delivering authentic cPanel Jupiter file management workflows.
File Manager & Chroot Architecture
Modal: #modal-file-manager

The File Manager offers a full dual-pane directory explorer: a collapsible recursive directory tree on the left, and an interactive file table on the right with multi-column sorting (Name, Size, Type, Last Modified, Permissions).

Chroot Jail & Path Normalization
Every filesystem request is normalized via path.resolve and checked against the root path. Any attempt to use directory traversal sequences (e.g. ../../Windows/System32 or null bytes) is instantly rejected with an HTTP 403 Forbidden error. 
const safePath = path.normalize(path.join(CHROOT_ROOT, requestedPath));
if (!safePath.startsWith(CHROOT_ROOT)) {
  throw new Error("Access Denied: Path Traversal Prohibited");

New-Tab Web Code Editor & Encoding Dialog
Route: /editor.html

Clicking Edit on any text file initiates authentic cPanel Jupiter behavior: first rendering a character encoding verification modal, followed by launching a dedicated, full-page code editor in a new browser tab.

Character Encoding Confirmation Dialog
Displays an alert advising users to back up original files prior to converting character sets. Allows selecting between utf-8 (default), us-ascii, iso-8859-1, windows-1252, big5, and shift_jis.
Ace Editor Capabilities (/editor.html)
  • Syntax Highlighting: Auto-detects 12+ programming languages based on file extension (PHP, HTML, JavaScript, CSS, JSON, SQL, Python, Shell, XML, Markdown, YAML, Plain Text).
  • Editor Controls: Find & Replace (Ctrl+F), Go to Line (Ctrl+L), Undo/Redo (Ctrl+Z / Ctrl+Y), Toggle Word Wrap, and adjustable Font Size (10px - 20px).
  • Save Engine: Directly submits payload to POST /api/files/save with chosen character encoding and displays real-time toast feedback.
  • Legacy Fallback: Provides a "Use legacy editor" toggle for switching seamlessly between Ace Editor and standard HTML <textarea>.
Directory Privacy (.htaccess Authentication)
Modal: #modal-fm-privacy

Directory Privacy password-protects any folder inside public_html. The system automatically creates or updates an Apache .htaccess file along with a companion .htpasswd file containing bcrypt or MD5 hashed credentials.

Backup Wizard & Full System Snapshots
Modal: #modal-backups

The Backup Wizard dumps all MariaDB/MySQL databases into individual .sql script files and packages all website files from htdocs into a consolidated, compressed .zip archive in data/backups/.

One-Click Generation: Backups run in the background with live percentage progress indicators and appear in the downloadable archive table immediately upon completion.
