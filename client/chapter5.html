Chapter 05

Detailed Module Implementation & Engineering

Technical Realization of 33+ Localhost Hosting Features

5.1 Core Subsystem Architecture

Chapter 5 documents the technical engineering behind the 33 integrated modules forming the core cPanel Localhost platform:

5.1 Jupiter UI & Modal Engine

Constructed with 33 top-level isolated .modal-overlay containers. Managed via centralized cPanelApp.openModal(id) with live tool search filters and responsive category collapse.

5.2 Chrooted File Manager

Features asynchronous directory reading, stream-based file uploaders, an in-browser code editor, and full ZIP extraction/compression using archiver and adm-zip.

5.3 MariaDB Orchestrator

Administers MySQL databases via mysql2 connection pool. Automatically calculates table counts and disk size in MB from information_schema.tables.

5.4 Apache Virtual Hosts & DNS

Directly generates Apache <VirtualHost *:80> blocks in httpd-vhosts.conf and maps DNS zone records (A, CNAME, MX, TXT) with automatic document root provisioning.

5.5 Advanced Automation, Cron Jobs & Diagnostics

The Advanced category delivers enterprise server automation on Windows:

  • Linux Cron Parser: Evaluates standard 5-part cron syntax (min hour day month weekday) with preset dropdowns and manual 'Run Now' execution capturing exit codes.
  • Dynamic Error Pages: Customizes 400, 401, 403, 404, and 500 error pages with token variables, writing HTML files and syncing ErrorDocument directives in .htaccess.
  • Track DNS Suite: Performs real-time DNS lookups via Node.js dns.promises, live ICMP pings via ping -n 4, and hops tracing via tracert -d -h 10.

5.6 Security Suite, MultiPHP & Authentic UAPI Gateway

5.6 SSL & IP Blocker Firewall

Inspects installed SSL/TLS certificates and generates self-signed certificates. IP Blocker injects native Apache Require not ip directives inside public_html/.htaccess.

5.7 MultiPHP & Software Suite

MultiPHP manager inspects active PHP runtime directives, toggles PHP extensions, and edits key directives (memory_limit, upload_max_filesize) directly in php.ini.

5.8 API Tokens & Authentic cPanel UAPI Protocol

A flagship achievement of this project is the native cPanel UAPI Compatibility Gateway (ALL /api/uapi/:module/:function) which enables legacy and modern tools expecting authentic cPanel responses to interact with localhost:

// Authentic cPanel UAPI Response Envelope (Mysql::create_database) { "status": 1, "module": "Mysql", "function": "create_database", "data": { "success": true, "dbName": "production_app" }, "errors": null, "messages": null, "metadata": {} }

Implemented modules include Fileman::list_files, Fileman::save_file, Mysql::create_database, DomainInfo::list_domains, Cron::add_line, and SSL::installed_hosts.
