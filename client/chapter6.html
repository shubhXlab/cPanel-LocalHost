AI Integration & Function Calling Subsystem

Autonomous LLM Orchestration, OpenAPI 3.0 & Agent Gateways

6.1 Dynamic OpenAPI 3.0.3 Specification Generation

To facilitate zero-configuration connectivity with modern AI models and developer tooling, the platform dynamically generates an authentic OpenAPI 3.0.3 Specification at GET /api/ai/openapi.json:

OpenAPI 3.0.3 Capabilities: Formally specifies all endpoints, path parameters, request bodies, and JSON schemas across File Manager, Databases, Virtual Hosts, Cron Jobs, SSL, Software, and System Resources. Designed for 1-click import into ChatGPT Custom GPT Actions and Swagger UI.

6.2 OpenAI & Claude Tool Calling Schemas (31+ Tools)

Modern Large Language Models (LLMs) utilize structured tool calling to interact with real-world systems. The endpoint GET /api/ai/tools provides native formatted definitions for both leading LLM architectures:

OpenAI Function Calling Format

Exports array of { type: "function", function: { name, description, parameters } } ready to be injected into OpenAI Chat Completions API or Assistants API.

Anthropic Claude Tools Format

Exports array of { name, description, input_schema } matching Anthropic Claude Messages API specification.

6.3 Single-Tool Universal Execution Gateway

For autonomous AI agents that prefer a consolidated interface rather than managing 30+ separate function schemas, the platform exposes the Universal AI Action Gateway at POST /api/ai/execute:

POST /api/ai/execute HTTP/1.1 Authorization: Bearer cptok_e3a5b8...dca0 Content-Type: application/json { "tool": "mysql_create_database", "parameters": { "name": "ai_ecommerce_db" } } HTTP/1.1 200 OK { "success": true, "tool": "mysql_create_database", "data": { "success": true, "dbName": "ai_ecommerce_db" } }

6.4 ChatGPT Custom GPT Integration Workflow

Integrating an autonomous AI agent takes less than 60 seconds with zero programming:

  • Step 1: In ChatGPT → Create Custom GPT → Actions → "Import from URL".
  • Step 2: Paste http://localhost:2083/api/ai/openapi.json.
  • Step 3: Configure Authentication Type to Bearer and paste the generated API Token.
  • Result: ChatGPT can autonomously create databases, write PHP scripts, configure subdomains, and schedule cron jobs on your local computer.
